Tecnologia Função Exemplo prático
HTML Linguagem de marcação que organiza e estrutura o conteúdo da página Inserir o texto de um título ou colocar a foto de um produto na tela
CSS Mecanismo de estilo focado no design e na estética Mudar a cor de fundo de um botão, alinhar um texto ao centro
JavaScript Linguagem de programação que introduz lógica, comportamento e dinamismo Abrir um menu ao clicar em um botão, validar se um e-mail foi preenchido corretamente

Boas práticas

  1. Não use div ou span para tudo. Elas não têm valor semântico
  2. Use tags estruturais: Divida sua página com elementos que organizam o layout.
  3. Respeite a hierarquia de títulos: Use de h1 a h6 em ordem correta.
  4. Use button quando a ação executa algo na página (abrir modal, enviar formulário).
  5. Use a (com atributo href) apenas quando a ação redireciona o usuário para outra página ou seção.
